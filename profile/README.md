# EduLinq ([edulinq.org](https://www.edulinq.org))

We are a 501(c)(3) nonprofit dedicated to creating free and open source software for education.
Our mission is to make educational tools for everyone.
We believe that everyone deserves a good education regardless of wealth or status, and we want to help make that possible.

We believe that educational software should be:

### Free

Free software is available without charge to anyone that can download it.
There should be no barriers on education, and wealth is perhaps the greatest barrier there is.
Whether that barrier comes in the form of money, time, or privilege.
As a software developer, we don't have the power to address all the issues that come with wealth inequality,
but at least we can make our software free.

### Open Source

Open source software has code that is always available to view and modify, anyone can see how the software works and improve upon it.
Our dedication to open source software is that same as our dedication to transparency and always improving.
It's impossible to foresee all the needs of people at one time, but because our software is available for all to improve,
we can tackle changes as they come.

### High Quality

High quality software is designed for interoperability and built robustly.
On the user side quality software should accomplish its task without frustrating the user and allow the user to work across multiple platforms.
On the development side quality software should be maintainable.
We take great care to always follow strong software engineering practices,
the [ACM Code of Ethics](https://www.acm.org/code-of-ethics), and our own moral compass.
We strive build software that is secure, interoperable, maintainable, and robust.


## Featured Projects

### Lynx Grader

The [Lynx Grader](https://github.com/edulinq/autograder-server) allows instructors to create new or integrate existing grading infrastructure into a secure system that:
 - accepts and tracks student submissions;
 - runs students' code in a secure, isolated, and customizable environment;
 - provides students feedback on their submissions;
 - saves and backs up submission history;
 - and uploads grades to a course management platform such as Canvas.

Links:
 - [Server](https://github.com/edulinq/autograder-server)
 - [Python Interface](https://github.com/edulinq/autograder-py)
 - [Web Interface](https://github.com/edulinq/autograder-web)

### Quiz Composer

The [Quiz Composer](https://github.com/edulinq/quiz-composer) allows instructors to create platform-agnostic quizzes (including exams and worksheets)
in a unified readable common layout and then quizzes can be instantiated in any number of formats automatically —
quizzes can be generated in Canvas, HTML forms, LaTeX, PDFs, or GradeScope.
The common format and tooling allows for frictionless collaboration when developing quizzes,
simple deployment for both online and paper quizzes, and seamless handoffs between terms.

Links:
 - [Source](https://github.com/edulinq/quiz-composer)
 - [Sample Quiz](https://github.com/edulinq/cse-cracks-course/tree/main/quizzes/regex)

### LMS Toolkit

The [LMS Toolkit](https://github.com/edulinq/lms-toolkit) is a Python interface and site of CLI tools to interact with different
[Learning Management Systems](https://en.wikipedia.org/wiki/Learning_management_system) (LMSs).
LMSs are pivotal for running large courses, but have inconsistent graphical interfaces and typically are not designed for programmatic access.
Once you learn one, moving between LMSs can be quite difficult. The LMS Toolkit provides users a unified, programmable interface to multiple LMSs.
This allows instructors to easily move between LMSs, and support features that may not explicitly encoded into a specific LMS's GUI.

Links:
 - [Source](https://github.com/edulinq/lms-toolkit)
 - [Canvas Test Image](https://github.com/edulinq/lms-docker-canvas-testdata)
 - [Moodle Test Image](https://github.com/edulinq/lms-docker-moodle-testdata)

### Pacai

[Pacai](https://github.com/edulinq/pacai) is an educational tool for AI in the guise of the Pac-Man game.
Originally developed for [UC Berkeley AI](https://inst.eecs.berkeley.edu/~cs188/archive/fa24/projects) courses,
we have rebuilt this project with from the ground up to improve performance, support, and accessibility.
Notable improvements include:
 - Upgraded to Python 3.10.
 - Added Python type hints.
 - Created a new web-based UI.
 - Added isolation between agents and the core game engine to prevent cheating.
 - Added the ability to save games as animated gifs.

Links:
